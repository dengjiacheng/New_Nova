# UI 流程与页面布局

## 页面结构

1. **启动页 / 登录页**
   - 输入：用户名、密码。
   - 显示当前 `pcId`（可复制用于排查）。
   - 登录成功后跳转仪表盘，并初始化 WS 连接。

2. **仪表盘**
   - 快捷卡片：余额、已购脚本数量、在线设备数。
   - 最近执行任务列表（状态、脚本、设备、时间）。
   - 系统通知列表（余额预警、脚本更新等）。

3. **设备管理页**
   - 顶部工具栏仅保留“全量刷新”、“连接 Wi-Fi”按钮和状态统计，不再提供搜索、筛选或批量操作入口。
   - 主体为单一设备列表，每行展示 ADB 采集的 `deviceId/名称`、连接方式（USB/Wi-Fi/未知）、本地状态（Online/Offline/未授权等）、云端状态（Online/Offline/被占用）以及操作按钮。
   - 表头固定为 `设备/名称`、`连接方式`、`本地状态`、`云端状态`、`PC_ID`、`操作` 六列，列宽按百分比分配，保证桌面宽度下均衡排版。
   - 联调阶段线框：
    ```
     +─────────────────────────────────────────────────────────────────────────────+
     | 顶部工具栏 56px                                                             |
     | ├─ 左：页面标题“设备管理” + 统计徽章（在线 / 总数 / 本地 / 云端仅）          |
     | ├─ 中：搜索框 [🔍 搜索设备 / Serial / PC]                                    |
     | └─ 右：按钮组 [全量刷新] [连接 Wi-Fi] [批量上线] [筛选 ▼]                  |
     +─────────────────────────────────────────────────────────────────────────────+
     |                                                                             |
     |  | 设备列表占据内容区域                                     |           |
     |  | ┌────────────────────────────────────────────────────────┤           |
     |  | │ 设备/名称 │ 连接方式 │ 本地状态 │ 云端状态 │ PC_ID │ 操作 │       |
     |  | │ Pixel 6 Pro│ USB     │ Online    │ Online    │ PC-123│ 上线…│       |
     |  | │ 192.168…   │ Wi-Fi   │ Offline   │ CloudOnly │ —     │      │       |
     |  | └────────────────────────────────────────────────────────┤           |
     |  |   滚动条；操作列包含上线/同步日志/复制 ID 等按钮                     |
     +─────────────────────────────────────────────────────────────────────────────+
     | 底部 Toast 区：展示 ADB/接口调用结果                                        |
     +─────────────────────────────────────────────────────────────────────────────+
     ```
   - 交互说明：
     - 列表支持勾选进入批量模式；符合权限的角色可批量上线。
     - Wi-Fi 连接按钮触发 `adb connect` 并在列表中即时呈现新设备。
     - “仅云端在线”行提示用户检查本地连接或执行 `adb connect`；冲突行标识占用的 `pcId`。
     - 操作列仅保留“上线”按钮，点击后 NovaDesk 会自动检测并安装激活版本的 Agent APK（含 SHA256 校验），随后再发起上线指令。
   - 角色差异：
     - `SUPER_ADMIN` 可额外看到“所属租户”和“切换控制权”按钮；`USER` 仅能操作 `pcId` 匹配的设备，其他项禁用并显示提示。
   - 空状态与响应式：
     - 无设备时展示插画 + “连接设备或刷新 ADB 列表”按钮；过滤无结果时显示“清除筛选”链接。
     - 窄屏场景下表格自动开启水平滚动，列标题固定在顶部；宽屏下保持 5 列布局。
   - 联调辅助：
     - 顶部工具栏新增“调试”图标，可在联调模式中展开对话框，展示最近请求的 traceId、WS 状态、Agent 心跳延迟；按钮仅 `ADMIN` 及以上可见。

4. **脚本商城/已购脚本页**
   - Tab 切换：全部脚本 / 已购脚本。
   - 展示脚本信息：名称、版本、能力、价格。
   - 未购脚本显示“购买”按钮，调用 `/scripts/{id}/purchase`。

5. **脚本详情页**
   - 脚本说明、版本信息、依赖能力。
   - 参数字段 schema 展示。
  - 模板管理区：
     - 模板列表、创建、编辑、复制、删除。
     - 模板文件保存状态（已保存/未保存）。
   - 执行面板：
     - 选择模板（下拉）；
     - 勾选设备（多选在线设备）；
     - 执行按钮，显示预计费用（设备数 × 单次执行费）。

6. **执行监控页**
   - 按设备分组的执行进度面板，展示步骤日志与当前状态。
   - 支持筛选 `pcId`、脚本、时间范围。
   - 历史记录列表（从 `/executions` 读取）。
   - 支持导出执行报告（JSON/CSV）。

7. **账单与审计页**
   - 显示消费流水、充值记录（来自 `/billing/transactions`）。
   - 支持筛选时间、类型、脚本。
   - 导出按钮生成 CSV。

8. **管理员工具（Admin Tools）**
   - 仅 `ADMIN`、`SUPER_ADMIN` 可见，普通用户完全隐藏导航入口。
   - 页面分为左右两栏：
     - 左侧卡片用于上传 Agent APK：
       - 表单字段：`APK 文件`（必填，文件选择器，限制 `application/vnd.android.package-archive`），`Version Name`、`Version Code`、`Release Notes`（Markdown 可选）。
        - 客户端自动计算 SHA256 校验值并随请求提交；拒绝非 `.apk` 文件或超过 200 MB 的文件，同时在上传前提示校验状态。
        - 支持显示当前签名的 `SHA256` 校验值，点击按钮可复制。
        - 上传进度条展示 `0-100%`，完成后弹出 Toast 并刷新版本列表。
      - 右侧为版本历史表格：
        - 列：`Version Name`、`Version Code`、`Uploaded By`、`Uploaded At`、`File Size`、`Checksum`、`Status`（`ACTIVE`/`ARCHIVED`）。
        - 提供操作按钮：`设为当前版本`（`ADMIN` 与 `SUPER_ADMIN` 可见）、`下载`（生成签名 URL）、`查看发布说明`。
        - 历史版本支持删除，删除时弹出确认对话框；若删除当前激活版本，NovaDesk 会在下一次检测时提示无可用版本。
   - 表单校验：
     - 上传前校验文件大小（默认不超过 200 MB）与后缀名。
     - Version Code 必须大于当前激活版本，若不是则需二次确认。
   - 交互细节：
     - 上传完成后自动调用 `GET /api/admin/agent-packages` 刷新列表。
     - 若后台已有正在处理的上传任务，按钮呈禁用状态并显示提示。
     - 支持手动刷新按钮与错误告警条展示服务器返回的错误码。
   - 日志：所有触发上传、设置当前版本的操作写入 `AppLogger` 并附带 `traceId`。

## 关键交互

- **多选执行**：选择多个设备时，应弹出确认提示，列出总费用、设备清单。
- **执行进度推送**：WS 消息到达时，若当前页面未聚焦对应任务，可使用系统通知或页内 Toast 提示。
- **余额不足**：执行失败时弹窗提示并引导至充值页面（或联系管理员）。
- **模板校验**：执行前对模板字段进行类型与必填校验，提示缺失字段。
- **错误重试**：执行失败后提供“重试”按钮，沿用原参数再次提交。

## UX 考量

- 状态颜色统一：在线（绿色）、执行中（蓝色）、失败（红色）、离线（灰色）。
- Loading/空状态友好提示。
- 日志视图支持关键字过滤、复制。
- 提供“显示/隐藏敏感字段”开关（例如密码）。

## 国际化与本地化

- 初期中文界面；保留 i18n 结构以便后续扩展。
- 所有文本使用 `AppLocalizations` 管理。

## 可访问性

- 支持键盘导航、屏幕阅读器标签（Flutter 可通过 `Semantics` 控制）。
- 颜色对比满足 WCAG AA 标准。

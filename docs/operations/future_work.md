# 后续规划与风险提醒

## 功能积压

- **脚本商城支付集成**：目前假设内部充值；未来可接入在线支付（微信/支付宝）。
- **模板云备份**：当前模板仅存本地，后续可提供云端同步或账号级共享。
- **Agent 自动更新**：现阶段需手动更新 APK，可考虑 OTA/后台下载。
- **脚本版本管理平台**：为开发者提供上传、审核、发布流程。
- **执行失败退款策略**：目前默认不退款，需明确 SLA 与用户协议。
- **多租户隔离增强**：将脚本授权与消费限制在租户层级（当前设计已满足，需补测试）。
- **OpenCV/IME 集成**：当前仅占位，未来需实现并增加能力检测。

## 技术风险

- **ADB 可靠性**：本地环境差异（驱动、权限）可能导致设备上线失败，需要充分的错误提示与重试策略。
- **WebSocket 稳定性**：PC/Agent 网络波动可能频繁重连，需要良好的重连与任务恢复逻辑。
- **模板安全**：本地存储敏感信息，需提醒用户妥善保护；考虑提供字段级加密。
- **计费一致性**：扣费在任务创建时完成，若后续系统异常需人工对账；建议配合交易对账脚本。
- **审计合规**：仅保留脚本执行/消费日志，若未来有监管要求需扩展范围。

## 性能指标（待确认）

- 最大并发设备数：由 Redis/Server 横向扩展决定。
- 心跳频率与容忍延迟需根据生产环境网络情况调整。
- 执行日志量较大时，Server 持久化性能需评估，可采用异步批量写入。

## 测试建议

- 本地集成测试：模拟多个 PC、多个设备上线、执行脚本。
- 压力测试：模拟高频脚本执行、WS 连接断开重连。
- 回归测试：脚本模板 schema 变化、Agent 升级。

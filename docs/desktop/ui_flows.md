# UI 流程与页面布局

## 页面结构

1. **启动页 / 登录页**
   - 输入：用户名、密码。
   - 显示当前 `pcId`（可复制用于排查）。
   - 登录成功后跳转仪表盘，并初始化 WS 连接。

2. **仪表盘**
   - 快捷卡片：余额、已购脚本数量、在线设备数。
   - 最近执行任务列表（状态、脚本、设备、时间）。
   - 系统通知列表（余额预警、脚本更新等）。

3. **设备管理页**
   - 左侧设备列表：显示 `deviceId`、别名、上线/下线状态、所属 PC（如冲突）。
   - 每项提供“上线/下线”按钮，显示当前脚本执行状态。
   - 顶部提供刷新、过滤（在线/离线）、导出（可选）。

4. **脚本商城/已购脚本页**
   - Tab 切换：全部脚本 / 已购脚本。
   - 展示脚本信息：名称、版本、能力、价格。
   - 未购脚本显示“购买”按钮，调用 `/scripts/{id}/purchase`。

5. **脚本详情页**
   - 脚本说明、版本信息、依赖能力。
   - 参数字段 schema 展示。
  - 模板管理区：
     - 模板列表、创建、编辑、复制、删除。
     - 模板文件保存状态（已保存/未保存）。
   - 执行面板：
     - 选择模板（下拉）；
     - 勾选设备（多选在线设备）；
     - 执行按钮，显示预计费用（设备数 × 单次执行费）。

6. **执行监控页**
   - 按设备分组的执行进度面板，展示步骤日志与当前状态。
   - 支持筛选 `pcId`、脚本、时间范围。
   - 历史记录列表（从 `/executions` 读取）。
   - 支持导出执行报告（JSON/CSV）。

7. **账单与审计页**
   - 显示消费流水、充值记录（来自 `/billing/transactions`）。
   - 支持筛选时间、类型、脚本。
   - 导出按钮生成 CSV。

## 关键交互

- **多选执行**：选择多个设备时，应弹出确认提示，列出总费用、设备清单。
- **执行进度推送**：WS 消息到达时，若当前页面未聚焦对应任务，可使用系统通知或页内 Toast 提示。
- **余额不足**：执行失败时弹窗提示并引导至充值页面（或联系管理员）。
- **模板校验**：执行前对模板字段进行类型与必填校验，提示缺失字段。
- **错误重试**：执行失败后提供“重试”按钮，沿用原参数再次提交。

## UX 考量

- 状态颜色统一：在线（绿色）、执行中（蓝色）、失败（红色）、离线（灰色）。
- Loading/空状态友好提示。
- 日志视图支持关键字过滤、复制。
- 提供“显示/隐藏敏感字段”开关（例如密码）。

## 国际化与本地化

- 初期中文界面；保留 i18n 结构以便后续扩展。
- 所有文本使用 `AppLocalizations` 管理。

## 可访问性

- 支持键盘导航、屏幕阅读器标签（Flutter 可通过 `Semantics` 控制）。
- 颜色对比满足 WCAG AA 标准。

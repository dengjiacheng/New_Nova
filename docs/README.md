# Nova 平台文档总览

本目录提供 Nova 分布式移动端自动化控制系统的设计与实现文档，支持文档驱动的并行开发。文档按组件与跨组件主题分类，涵盖架构、流程、接口、数据模型及运维策略。

## 文档结构

- `architecture/`：系统级架构说明、拓扑、组件职责与消息协议总览。
- `flows/`：关键业务流程（设备上线、脚本执行、计费等）的时序与状态说明。
- `server/`：NovaServer 云服务端的模块划分、REST/WS API、数据模型及后台任务。
- `desktop/`：NovaDesk 桌面客户端的架构、设备管理、脚本模板管理与 UI 流程。
- `agent/`：NovaAgent Android 端运行器的生命周期、内置脚本管理与指令处理。
- `operations/`：跨组件的 RBAC、计费结算、审计策略、配置部署、开发规范、协作入口与未来规划。

> 新成员或并行会话请从 `operations/onboarding.md` 开始阅读，按指南进入对应组件的文档与 To-Do 流程。

后续若需扩展新的专题，可在对应目录继续补充文档，并在此处登记索引。
